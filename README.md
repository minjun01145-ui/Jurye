# JRCRAFT V2 Phase 1

이 폴더는 기존 안정본을 덮어쓰지 않는 1차 V2 작업본입니다.

## 포함 범위
- 새 고정 상단 셸
- 흐린 홈 배경 위 인증/프로필 오버레이
- 펑키 배너와 픽셀 반짝 장식
- 혼자하기/멀티플레이 홈
- 세트 선택
- 개인 게임 선택
- 캐릭터 상점 기본 화면
- 학생 멀티 대기실 기본 화면
- 새로운 CSS 파일 구조

교사 화면과 개별 게임 화면은 기능 보존을 위해 Phase 1 임시 구조 스타일만 적용되어 있습니다. 다음 단계에서 순서대로 완전히 교체합니다.

## 설치
1. 기존 프로젝트를 통째로 백업합니다.
2. 이 폴더의 `index-v2.html`, `index-v2.mjs`, `styles/`, `src/v2/`를 기존 프로젝트 루트에 복사합니다.
3. 기존 프로젝트의 `char/`와 `src/utils/` 폴더는 그대로 둡니다.
4. Live Server에서 `index-v2.html`을 엽니다.

## 정식 파일명으로 시험할 때
- `index-v2.html` → `index.html`
- `index-v2.mjs` → `index.mjs`
- HTML 마지막 script의 파일명도 함께 바꿉니다.

처음에는 V2 파일명 그대로 테스트하는 편이 안전합니다.


## FIX1 수정 사항

- 인증 후 로딩 화면이 100%에서 멈추던 오류 수정
- 새 로딩 화면의 `loading-title`이 `h1`인데 기존 코드가 `h2`를 찾던 문제 수정
- 동일한 오래된 로딩 제목 접근 5곳을 모두 안전한 공통 함수로 교체
- 불필요한 `lobby-mode-back-btn` 경고 제거
- 교사용 대기실의 실제 나가기 버튼 복구


## FIX2 수정 사항

- JRCRAFT 로고 오른쪽에 현재 위치 이동 경로(브레드크럼) 추가
- 예: `로그인 화면 › 시작 화면 › 혼자하기 · 학습 세트 선택 › 게임 선택`
- 이전 단계 항목을 클릭하면 해당 화면으로 즉시 이동
- `시작 화면` 클릭 시 혼자하기/멀티플레이 선택 화면으로 복귀
- 게임 선택 화면에는 현재 선택한 학습 세트 제목도 함께 표시
- 화면 폭이 좁아지면 이동 경로가 가로로 자연스럽게 스크롤됨
- 프로필 설정을 마치지 않은 상태에서는 시작 화면으로 우회 진입하지 못하도록 보호


## PHASE 2 수정 사항

이번 단계에서는 멀티플레이 영역을 집중적으로 개편했습니다.

- 교사용 멀티플레이 화면을 세로형 구형 화면에서 데스크톱 제어판 구조로 전면 교체
- 왼쪽: 게임 설정 및 실행 제어
- 오른쪽: 학생 모니터링, 라이브 순위표, 전체 채팅
- 교사 옵션의 기능 ID와 기존 로직은 그대로 유지
- 학생 대기실 캐릭터 카드를 새 어두운 네온 디자인으로 변경
- 교사용 학생 카드와 조별 묶음 UI를 클래스 기반으로 재작성
- 대기실 채팅 메시지를 인라인 스타일 없이 클래스 기반 말풍선으로 변경
- 교사 라이브 순위표를 새 어두운 UI로 변경
- 학번·이름 표시 토글 및 게임 종료 복귀 버튼의 구형 색상 인라인 스타일 제거
- 사용되지 않던 구형 teacher-match-screen 제거
- 중복 DOCTYPE 정리

다음 단계에서는 학습 목록, 게임 옵션, 결과, 피드백, 개인 랭킹 화면을 같은 디자인 체계로 교체할 예정입니다.


## PHASE 3 수정 사항

이번 단계에서는 혼자하기의 보조 화면과 결과 화면을 전면 개편했습니다.

- 학습 목록을 데스크톱형 3열 테이블 구조로 변경
- 영어 가리기 / 뜻 가리기 버튼을 상태형 토글 UI로 변경
- 깜박이 순서 선택 화면을 두 개의 큰 선택 카드로 변경
- 플레이 시간 선택 화면을 10초 / 3분 / 5분 카드 구조로 변경
- 게임 결과 화면을 점수 중심의 대형 결과 카드와 다음 행동 패널로 변경
- 의견 작성 화면을 좌우 분할형 폼으로 변경
- 개인 랭킹 화면을 요약 패널 + 랭킹 보드 구조로 변경
- 랭킹 목록을 JS 인라인 HTML 대신 클래스 기반 DOM 렌더링으로 변경
- 하이파이브 조편성 결과를 조별 카드와 학생 캐릭터 목록 구조로 변경
- 피드백 화면의 현재 위치 경로가 실제 진입 경로를 반영하도록 수정

다음 단계에서는 캐릭터 상점, 관리자 화면, 문제 만들기 및 쇼케이스 화면을 같은 디자인 체계로 옮길 예정입니다.
